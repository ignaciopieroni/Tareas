# Tareas

Aplicación web para la gestión de tareas personales y colaborativas. Permite crear proyectos, organizar tareas, administrar organizaciones y trabajar con múltiples usuarios y equipos mediante permisos.

## Funcionalidades principales

- Registro e inicio de sesión de usuarios.
- Creación de proyectos personales u organizacionales.
- Creación de tareas con título, descripción y fecha límite.
- Marcado de tareas como completadas.
- Filtros por estado y fecha.
- Creación y administración de organizaciones.
- Gestión de integrantes y permisos.
- Visualización de tareas en calendario.
- Sincronización de cambios en proyectos compartidos.

## Conceptos aplicados

- Análisis de requisitos funcionales y no funcionales.
- Modelado de casos de uso.
- Gestión de usuarios, roles y permisos.
- Diseño de flujos de datos.
- Arquitectura pensada para escalabilidad y mantenibilidad.
- Validaciones de seguridad en backend.
- Interfaz simple, accesible y responsive.

## Casos de uso desarrollados

- Crear proyecto.
- Crear tarea.
- Ver calendario con tareas.
- Crear organización.
- Buscar y unirse a una organización.
- Administrar organización.
- Cerrar tareas de un proyecto.

## Objetivo del proyecto

El objetivo de **Tareas** es resolver una necesidad concreta: mejorar la organización personal y colaborativa mediante una plataforma simple, eficiente y adaptable a distintos contextos de uso, como el ámbito educativo, laboral o personal.
